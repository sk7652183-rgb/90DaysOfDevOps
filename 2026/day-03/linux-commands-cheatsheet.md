 File & Directory Management:
 mkdir folder_name — Create a new directory
 touch file_name — Create a new empty file
 vim file_name — Open file in vim editor
 cp source destination — Copy a file
 mv source destination — Move or rename a file
 rm -r folder_name — Remove directory recursively
 find . -name "file_name" — Find a file in system
 cat file_name — View file content

 System Monitoring:
 ps aux — Show all active processes
free -m — Check memory usage
du -sh folder_name — Check directory size
uname -r — Check Linux kernel version
whoami — Show currently logged in user

 Text Processing:
 grep "keyword" file_name — Filter pattern from file
 sort file_name — Sort file content line by line

 User Management:
 useradd username — Add a new user
 sudo su — Switch to root user
 chmod 755 file_name — Change file permissions

 Service & Process Management:
 systemctl status service_name — Check service status
 nohup script.sh & — Run script in background

 Networking Commands:
ping google.com - Check network connectivity to a host
netstat -tulnp - Show all active connections and open ports
curl https://url.com - Test a URL or API endpoint
ifconfig / ip addr - Show IP address and network interface details
